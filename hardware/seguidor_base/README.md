# Esquemático rev 1.0 (KiCad): histórico

Gerado por `ferramentas/esquematico/gen.py` em 04/11/2026 e importado no EasyEDA Pro para começar o layout.

Desde então, o esquemático evoluiu só no EasyEDA:
- QRE internos S2/S3 (D8/D9) e suas redes;
- C1/C2 eletrolíticos SMD;
- J3 com pads SMD embaixo;
- C19/C20 montados.

O `gen.py` recebeu só a troca de R14/R15 para 910 Ω. **O esquemático da placa encomendada é o que está dentro do `.epro` do v10** (`hardware/placa_base/`), e a BOM final é `hardware/placa_base/BOM_v10.csv`.
